¿Cómo publico los cambios?
  1. Pulsa «Descargar catálogo para publicar». Se descarga el archivo catalogo.js.
  2. En GitHub abre la carpeta js del repositorio, elige Add file → Upload files y sube catalogo.js (reemplaza al anterior). Pulsa Commit changes.
  3. En uno o dos minutos los clientes verán los cambios. Si usas el sitio desde una carpeta, copia el archivo en js/.
